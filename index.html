All conversion happens on your device using ffmpeg compiled to WebAssembly — nothing is uploaded anywhere. The engine (~30 MB) is fetched once from a CDN on first use and cached by your browser after that; everything works offline once it's loaded. First run needs an internet connection. Very unusual codecs inside some .mov files (e.g. ProRes) may not decode — standard iPhone/camera H.264 or HEVC .mov files work fine.

If this file was opened directly (file://) and nothing loads, some browsers block module scripts from local files. Serve the folder with any one-line local server instead, e.g. python3 -m http.server or npx serve, then open the printed localhost address. GitHub Pages works with no extra steps.
